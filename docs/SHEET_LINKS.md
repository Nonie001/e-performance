# ดัชนีแหล่งข้อมูล E-Performance

ไฟล์ลิงก์ใช้งานจริงอยู่ที่ `docs/SHEET_LINKS.local.md` ในเครื่องนี้ ไฟล์นั้นรวมลิงก์ชีตหลักและลิงก์ไฟล์ประเมินรอบ 2 แยกตามรหัสหัวหน้า และถูกกันออกจาก GitHub เพราะเป็นทางเข้าข้อมูลพนักงานและคะแนนประเมิน

## จุดอ้างอิงในโค้ด

| ข้อมูล | ตำแหน่งในโค้ด | ใช้ทำอะไร |
|---|---|---|
| ชีตประเมินหลัก | `google-apps-script/Code.gs` → `SPREADSHEET_ID` | บัญชี, EF Code, สายหัวหน้า–ลูกน้อง |
| คะแนน HR | `google-apps-script/Code.gs` → `HR_SPREADSHEET_ID` | คะแนน HR และ KPI |
| คะแนนรอบ 2 | `Hierarchy for evaluate` คอลัมน์ AE/AG | รหัสหัวหน้า → ลิงก์ไฟล์ประเมินของหัวหน้า |
| แท็บคะแนนในไฟล์หัวหน้า | `Score record` และ `บันทึกการประเมิน` | คะแนนตนเองและคะแนนหัวหน้า โดยตัวเลขในแท็บบันทึกการประเมินจะมีลำดับความสำคัญกว่า |

คำอธิบายเกณฑ์คะแนนอยู่ในแท็บ `INDEX` ของไฟล์แบบประเมินแต่ละ `EF-XX` ภายในโฟลเดอร์แบบฟอร์มประจำปี 2568 ส่วนลิงก์ไฟล์แบบประเมินปี 2569 และแท็บคำตอบฟอร์มที่ได้รับเพิ่ม บันทึกไว้ในไฟล์ลิงก์ภายในเครื่องแล้ว

ถ้าลิงก์ไฟล์รอบ 2 เปลี่ยน ให้แก้ **ชีต `Hierarchy for evaluate` คอลัมน์ AE/AG** เป็นหลัก แล้วปรับไฟล์ลิงก์ในเครื่องให้ตรงกัน
